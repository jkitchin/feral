# API reference

The rustdoc-generated API reference is published alongside this book:

- [`feral`](api/feral/index.html) — the main crate.
- [`feral_amd`](api/feral_amd/index.html) — clean-room AMD ordering.
- [`feral_amf`](api/feral_amf/index.html) — AMF ordering.
- [`feral_metis`](api/feral_metis/index.html) — METIS ordering wrapper.
- [`feral_scotch`](api/feral_scotch/index.html) — Scotch ordering wrapper.
- [`feral_kahip`](api/feral_kahip/index.html) — KaHIP ordering wrapper.
- [`feral_ordering_core`](api/feral_ordering_core/index.html) — shared
  ordering types.

If a link is missing, it usually means the workspace member did not produce
rustdoc on the most recent deploy — check the
[Pages workflow](https://github.com/jkitchin/feral/actions/workflows/pages.yml).
