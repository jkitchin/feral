* 02:10 :issue-199:pounce880:certification:
Substantive caveat recorded for the review. ω ≤ u certifies *backward*
stability; #880's symptom is a materially wrong =x= returned under
=Optimal=, which is a *forward*-error question, and forward error is
bounded by κ·ω, not ω. More pointedly, the issue's own instrumented
evidence shows the existing gate reading =1.470e-06= against a =1e-6= cut
— "the true error to three digits" — and rejecting all three calls. On
that instance the estimator measured correctly and the cascade discarded
its verdict. The analytic rotated-spectrum failure mode is argued but not
demonstrated on the failing instances, so a differently-founded
instrument should not be expected to close #880 by itself.

solves) is already public *and released* in 0.17.0 — but only via

forward bound would need its own exposure decision.
