* 18:27 :ci:clippy:toolchain:
CI installs dtolnay/rust-toolchain@stable, now 1.100.0
(0ef1bc386 2026-11-09). Its clippy reports needless_range_loop on
`for k in lo..hi { let x = a[k]; ... }`. `cargo clippy --workspace
--all-targets` on d3f7eb6 fails in feral-metis first (8 errors); 46
sites in total across feral, feral-metis, feral-scotch, feral-kahip,
feral-ordering-core, feral-diagnostics and two test files. None came
from PR #231: main itself fails. Fix: rewrite each loop as a slice
iteration (`for &x in &a[lo..hi]`, `.iter().map(|&x| x as usize)`,
`enumerate()` where the index is used elsewhere, `fill(0.0)`). The
same elements are read in the same order, so the numerics are
unchanged. I chose this over allowing the lint or pinning the
toolchain because it fixes the code rather than hiding the lint.
35 sites were converted by a pattern script and 11 by hand.
