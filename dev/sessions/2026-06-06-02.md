## Decisions Made

- Regression guard = exact structural invariant `heap_init_slots == n +
  touched_total`, not a growth ratio (the latter is invalid where legitimate
  work is super-linear). Recorded in commit 767b0d9.
- scaling_sweep generators are banded (GEN_BAND=16) so a generated ladder
  isolates per-phase scaling instead of pathological-fill artifacts.

## Abandoned Approaches

- Growth-ratio guard on total heap work (heap_init_slots(8k)/heap_init_slots(1k)
  < 16): rejected — on a hard random matching `touched_total` is itself
  quadratic (long augmenting paths: 52727→2.7M over 8× n), so the fixed code
  would also fail the ratio. Replaced by the exact structural invariant.
- Full-range random off-diagonals in the generated families: rejected —
  produced ~n^2.5 numeric loop (pathological fill), a generator artifact not a
  solver property. Replaced by constant-bandwidth generators.
