**Minor bump, not patch, and the reason is stated in the tag.** #171 made
`SparseLu::factor` default to threshold-Markowitz, which chooses its column
order during the factorization and ignores `factor`'s `symbolic` argument.
A caller passing a chosen ordering now factors something different unless
it pins `LuPivoting::GilbertPeierls`. That is a breaking behaviour change.

**Fixed a real docs defect found while preparing the release.** The
`SparseLuSymbolic` module header and all four constructors (`analyze`,
`analyze_with`, `analyze_triangularized`, `analyze_amd_only`) argue at
length about which ordering to prefer and what the default costs. Every one
of those comments was written when the ordering computed there was the one
`factor` used; under the 0.16.0 default it is not read at all beyond a
dimension check. Shipping them unchanged would have documented a decision
the library no longer makes. All five now open by saying so and point at
`used_markowitz()`. `LuParams::dense_bump_max_dim` got the matching note:
it was already gated on a triangularized symbolic and is now gated on
`GilbertPeierls` as well, so under the shipped defaults it is inert twice
over, and reaching it takes all three of `GilbertPeierls` +
`analyze_triangularized` + a non-zero cap.

Verified this added no new broken intra-doc links by diffing `cargo doc`
warnings against a stashed baseline: the same three warnings in the touched
files, at shifted line numbers (159->189, 190->225, 9->18).

**Also corrected:** the `[Unreleased]` changelog described
`dense_bump_max_dim` as "added in 0.15.2". No such version exists.

## Decisions Made

None architectural. The #171 decision was recorded in `dev/decisions.md`
last session; this session only shipped it.

One process decision worth carrying: `cargo publish --dry-run` belongs in
the release sequence *before* `gh release create`, not after. The release
trigger is irreversible and fires both publish workflows; a packaging
failure discovered afterwards leaves a tagged release that cannot be
re-cut at the same version. This is not in `scripts/release-checklist.sh`
yet — see "Next Session Should".

## Abandoned Approaches

the start of the log *and* took its exit code from `tail` rather than from
